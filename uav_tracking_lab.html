📖 Educational Theory — Clohessy-Wiltshire (Hill) Equations ▶
The Clohessy-Wiltshire (CW) or Hill equations describe the relative linearized motion of a deputy spacecraft with respect to a chief spacecraft in a circular orbit using the Local-Vertical Local-Horizontal (LVLH) coordinate frame:
ẍ - 2n ẏ - 3n²x = 0 (Radial differential equation)
ÿ + 2n ẋ = 0 (Along-track differential equation)
z̈ + n²z = 0 (Cross-track differential equation)
Coordinate System Mapping:
  • x (Radial): Direction along the vector from Earth center to chief spacecraft.
  • y (Along-Track): Direction parallel to chief orbital velocity vector.
  • z (Cross-Track): Direction normal to orbital plane.
  • n: Mean orbital angular rate $\sqrt{\mu / a^3}$ ($\text{rad/s}$), Period $T = 2\pi / n$.
Analytical State-Transition Solution:
x(t) = (4 - 3 cos nt) x₀ + (sin nt / n) vx₀ + (2(1 - cos nt) / n) vy₀
y(t) = 6(sin nt - nt) x₀ + y₀ - (2(1 - cos nt) / n) vx₀ + ((4 sin nt - 3nt) / n) vy₀
z(t) = cos nt z₀ + (sin nt / n) vz₀
Zero Drift / Bounded Motion Condition: To eliminate the secular linear drift term $-6n(x₀ + 2vy₀/n)t$ in $y(t)$, the initial velocity must satisfy vy₀ = -2 n x₀.
